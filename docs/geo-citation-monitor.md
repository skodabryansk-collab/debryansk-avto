# Мониторинг цитирования в AI-поиске

`geo:check` и `geo:citations` решают разные задачи:

- `pnpm run geo:check` — детерминированная SEO/GEO-регрессия публичного HTML, `robots.txt`, `sitemap.xml` и `llms.txt`;
- `pnpm run geo:citations` — измерение фактических ответов Google AI Overviews, Bing Copilot, Perplexity и ChatGPT с веб-поиском.

## Набор запросов

Набор содержит 20 нейтральных локальных запросов по четырём интентам: новые автомобили и дилерские центры, автомобили с пробегом, сервис и выкуп. Запросы не утверждают наличие скидок, цены, автомобилей в наличии, лидерство или другие коммерческие claims.

```bash
pnpm run geo:citations -- --list-queries
pnpm run geo:citations -- --list-sources
```

У каждого запроса есть стабильный `queryId`, интент и целевая страница сайта. Не меняйте текст запроса без необходимости: стабильный `queryId` нужен для сравнения недель.

## Формат экспорта

Сначала выполните каждый запрос в нужном продукте и сохраните его ответ и видимые citations в одном JSON-файле. Поддерживаются Google AI Overviews, Bing Copilot, Perplexity и ChatGPT с веб-поиском. Формат:

```json
{
  "checkedAt": "2026-08-26T09:00:00Z",
  "responses": [
    {
      "provider": "perplexity",
      "queryId": "new-dealer",
      "answerText": "Текст ответа…",
      "citations": [
        {
          "url": "https://example.com/source",
          "title": "Название источника"
        }
      ]
    }
  ]
}
```

Допустимые сокращения:

- `provider`: `google`, `bing`, `copilot`, `perplexity`, `chatgpt` или полные идентификаторы из `--help`;
- вместо `queryId` можно передать точное поле `query`;
- вместо `answerText` — `text`, `answer`, `content` или `response`;
- вместо `citations` — `sources` или `references`;
- citation может быть строкой URL или объектом с `url`, `link` или `href`.

Если у провайдера нет citation-ссылки, оставьте массив пустым — это будет честно зафиксировано как отсутствие ссылки. Не добавляйте ссылку на сайт вручную, если её не показал сам провайдер.

## Еженедельный автоматический замер

Для планового запуска используйте отдельную команду:

```bash
pnpm run geo:citations:weekly
```

Команда всегда запускает один и тот же набор из 20 `queryId` у всех четырёх провайдеров. Этот набор сохраняется в `runs[].queryIds` и `runs[].providers[].queryIds`, чтобы недельные запуски можно было сравнивать машинно. Команда добавляет в историю только ответы, которые действительно вернул API, и сохраняет отдельный блок `runs` со статусом источника каждого провайдера. Поэтому недоступный API не превращается в ложный результат «Дебрянск Авто не упомянут».

Команду можно подключить к системному планировщику, например запускать каждую неделю по понедельникам в 09:00:

```cron
0 9 * * 1 cd /path/to/project && pnpm run geo:citations:weekly >> .local/geo-citation-weekly.log 2>&1
```

### Источники и переменные окружения

Посмотреть текущую конфигурацию без запуска замера:

```bash
pnpm run geo:citations -- --list-sources
```

- **Perplexity**: официальный `https://api.perplexity.ai/chat/completions`, ключ `GEO_PERPLEXITY_API_KEY` (или `PERPLEXITY_API_KEY`), модель `sonar`; URL и модель можно переопределить через `GEO_PERPLEXITY_API_URL` и `GEO_PERPLEXITY_MODEL`.
- **ChatGPT с веб-поиском**: официальный OpenAI Responses API с инструментом `web_search_preview`, ключ `GEO_CHATGPT_API_KEY`, `OPENAI_API_KEY` или `AI_INTEGRATIONS_OPENAI_API_KEY`; модель `GEO_CHATGPT_MODEL` (по умолчанию `gpt-4.1`). URL можно переопределить через `GEO_CHATGPT_API_URL`.
- **Google AI Overviews**: стабильный публичный API получения ответа не предоставлен, поэтому недельный запуск сохраняет статус `unavailable` и не создаёт `checks`.
- **Bing Copilot**: стабильный публичный API получения ответа не предоставлен, поэтому недельный запуск сохраняет статус `unavailable` и не создаёт `checks`.

Если API-ключ отсутствует или конкретный вызов завершился ошибкой, это видно в `runs[].providers[]` и в недельном summary. Такие провайдеры не участвуют в расчётах mention rate и citation rate.

## Запись и сравнение

```bash
pnpm run geo:citations -- --input ./geo-citation-responses.json
pnpm run geo:citations -- --summary
```

По умолчанию история сохраняется в `.local/geo-seo-citations.json`; путь можно изменить:

```bash
pnpm run geo:citations -- --input ./geo-citation-responses.json \
  --report ./reports/geo-seo-citations.json
```

Для каждого зафиксированного ответа сохраняются:

- дата и ISO-неделя проверки;
- провайдер и стабильный запрос;
- упоминание `Дебрянск Авто`;
- наличие ссылки на домен `debryansk-auto.ru`;
- все найденные цитируемые страницы сайта;
- глобальная позиция ссылки и позиция среди ссылок сайта;
- целевая страница запроса для поиска контентных пробелов.

Еженедельный блок содержит coverage набора запросов, фактическое покрытие 80 возможных пар «провайдер × запрос», mention rate, citation rate, разбивку по провайдерам и запросам, наиболее цитируемые страницы и страницы без цитат. Незапущенные запросы не считаются отрицательным результатом: они показываются отдельно как `not-run`, а недоступные провайдеры — как `unavailable`.

## Ограничения измерения

Это мониторинг наблюдаемых ответов, а не утверждение о полном охвате поисковой выдачи. AI-ответы могут различаться по аккаунту, региону, времени, настройкам веб-поиска и экспериментам интерфейса. Проверяйте все четыре провайдера одинаковым набором запросов не реже одного раза в неделю и храните исходные экспортированные ответы отдельно, если нужна ручная перепроверка.
