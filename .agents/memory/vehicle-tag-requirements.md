---
name: New-car price tag requirements
description: User-approved constraints for printed new-car display tags.
---

New-car information tags are displayed in shopping centers, not inside dealerships. Use a single portrait A4 page that remains readable in black-and-white printing.

- Brand the tag as «Дебрянск Авто», with the logo tagline «Пространство автомобилей» at the same visual size and style as the former tagline.
- Do not include a vehicle photo or selling price. VIN is optional and must not take priority over model options.
- Prioritize the model, available trim levels, engines, transmissions, drive types, and technical specifications.
- Include a QR code linking to the matching model collection on the website.
- Remove generic sales slogans and avoid the old «Автомобили в наличии / официальный дилер Брянск» header.

**Why:** the user explicitly clarified the display context, print constraints, brand, and information priority.

**How to apply:** use these constraints for future new-car tag designs and implementation unless the user changes them.
